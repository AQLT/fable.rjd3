# X-13ARIMA seasonal adjustment (JDemetra+ v3)

Defines an X-13ARIMA model to be used inside
[`fabletools::model()`](https://fabletools.tidyverts.org/reference/model.html).
The model is estimated with
[`rjd3x13::jx13()`](https://rjdverse.github.io/rjd3x13/reference/x13.html)
and the Java result is kept in the fitted model, so that all JDemetra+
indicators can be extracted afterwards (see
[`jd3_indicator()`](https://aqlt.github.io/fable.rjd3/reference/jd3_indicator.md)).

## Usage

``` r
X13(
  formula,
  spec = c("rsa4", "rsa0", "rsa1", "rsa2c", "rsa3", "rsa5c"),
  context = NULL,
  ref_spec = spec,
  ...
)
```

## Arguments

- formula:

  Model formula: the name of the variable to adjust (`y`), or
  `y ~ specials` (see
  [jd3_specials](https://aqlt.github.io/fable.rjd3/reference/jd3_specials.md)).

- spec:

  Base specification: a character name (see
  [`rjd3x13::x13_spec()`](https://rjdverse.github.io/rjd3x13/reference/x13_spec.html)
  for the available names; the default is the first one) or a
  specification object from
  [`rjd3x13::x13_spec()`](https://rjdverse.github.io/rjd3x13/reference/x13_spec.html).
  The specials of the formula are applied to it.

- context:

  A modelling context created with
  [`rjd3toolkit::modelling_context()`](https://rjdverse.github.io/rjd3toolkit/reference/modelling_context.html)
  (e.g. for custom calendars), or `NULL`.

- ref_spec:

  Reference specification stored in the model: it is the reference of
  the refresh policies used by
  [`refit()`](https://generics.r-lib.org/reference/refit.html) and
  [`stream()`](https://fabletools.tidyverts.org/reference/stream.html).
  Defaults to `spec`, that is the specification before its modification
  by the specials.

- ...:

  Currently unused.

## Value

A model definition that can be passed to
[`fabletools::model()`](https://fabletools.tidyverts.org/reference/model.html).
Once fitted, the mable column contains a `jd3_model` object. Use
[components()](https://aqlt.github.io/fable.rjd3/reference/jd3_model_methods.md)
to get the decomposition as a `dable` (columns `trend`, `seasonal`,
`irregular` and `season_adjust`).

## Details

The specification can be set in two (combinable) ways:

1.  **Ex ante**, with the `spec` argument: a name or a specification
    object created with
    [`rjd3x13::x13_spec()`](https://rjdverse.github.io/rjd3x13/reference/x13_spec.html)
    and modified with the `set_*()` functions of rjd3toolkit.

2.  **In the formula**, with specials such as
    [`transform()`](https://rdrr.io/r/base/transform.html) or `xreg()`
    (see
    [jd3_specials](https://aqlt.github.io/fable.rjd3/reference/jd3_specials.md)).
    This is the only way to use regressors that are columns of the
    tsibble.

Specials override the base `spec`.

y <- tsibble::as_tsibble(AirPassengers)

# Default specification
mb <- model(y, x13 = X13(value))

# Specification created ex ante with rjd3toolkit
my_spec <- rjd3x13::x13_spec("rsa3")
my_spec <- rjd3toolkit::set_transform(my_spec, fun = "Log")
mb <- model(y, x13 = X13(value, spec = my_spec))

# Specification set in the formula with specials
mb <- model(
  y,
  x13 = X13(value ~ transform(fun = "Log") +
              outlier(outliers.type = c("AO", "LS")))
)

# Regressor taken from a column of the tsibble
y$shock <- as.numeric(y$index == tsibble::yearmonth("1955 Jan"))
mb <- model(y, x13 = X13(value ~ xreg(shock, regeffect = "Series")))
